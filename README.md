# 视频片段对比（Video Clip Compare）

一个轻量的 Windows 双轨 A/B 视频对比工具，用 tkinter + OpenCV 写，只有一个脚本，不需要装大型框架。

做这个是因为 DJV 这类播放器功能太多、全是英文；这里只保留做对比真正要用的东西：两条时间轨、四种对比方式、拖动对齐、只比重叠段。

## 功能

- **双轨独立时间轴**：A / B 两条轨道上下排列，各自可以用鼠标左右拖动改起点，对齐版本差异
- **只对比重叠段**：两段时长不同也能用，播放、逐帧、扫帧都锁在重叠区间内，非重叠部分在轨道上显示为灰色
- **四种对比方式**
  - 擦除（wipe）：一条红色分割线，左右两侧分别显示 A / B，抓中间红色把手拖动
  - 叠加（overlay）：A/B 混合，透明度滑条 0–100
  - 差分（difference）：逐像素差值并放大，看画面改动的区域
  - 并排（side by side）：左右各半屏
- **画面内扫帧**：在画面里按住左键横向拖动就是扫帧，按 A 的帧率吸附，拖满一屏≈走完整个重叠段
- **时间轴操作**：点刻度行跳帧，拖轨道改起点，滚轮缩放时间范围
- **中文界面 + 自带图标**

## 界面布局

```
工具栏（打开 A/B · 模式 · 透明度 · 播放 · 逐帧 · 时间码）
画面（A|B 合成，可拖扫帧）
时间刻度行
A 轨道
B 轨道
状态栏（片名、时长、重叠时长、B 偏移）
```

## 运行

需要 Python 3.7+，依赖三个库：

```
pip install opencv-python numpy pillow
```

双击 `视频片段对比.pyw` 即可（无控制台窗口），或：

```
pythonw 视频片段对比.pyw
```

## 快捷键

| 键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 逐帧后退 / 前进 |
| Ctrl+O | 打开 A |
| Ctrl+Shift+O | 打开 B |

## 打包成 exe（可选）

```
pip install pyinstaller
pyinstaller -F -w -i 视频片段对比.ico --add-data "视频片段对比.ico;." --add-data "视频片段对比.png;." 视频片段对比.pyw
```

## 已知限制

- 只解码视频画面，不处理音频
- 不支持 EXR / 图片序列，按单文件视频处理
- 帧精度以 A 轨的帧率为准，B 轨帧率不同时按时间取最近帧
